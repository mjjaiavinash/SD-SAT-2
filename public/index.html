Round 3: High-Level Design (HLD) Architecture

Interactive system design model demonstrating client request routing, microservice layers, caching, and event-driven architecture.

Architectural Component Flow

Conceptual / Simulated Implemented & Running
01

Product Service

Implemented

Encapsulates catalog management. Interacts with SQLite for persistent storage and the In-Memory Cache layer to serve reads rapidly without hitting disk.

  • REST CRUD endpoints (`/api/products`)
  • Search and category filtering
  • Automatic cache eviction on write/delete
02

Cart & Inventory Services

Implemented

Maintains user shopping sessions, verifies stock availability against inventory, and prevents race conditions with atomic stock deductions.

  • Live stock quantity verification
  • Atomic inventory reservation
  • Subtotal, tax, and total calculation
03

Order & Payment Services

Implemented

Orchestrates transaction workflow: validates customer payload, authorizes simulated payment, reserves inventory, creates order, and dispatches events.

  • Simulated Payment Gateway
  • Atomic multi-table SQLite inserts
  • Asynchronous event generation
04

Delivery & Notification Services

Implemented

Event-driven subscribers. Delivery Service updates order stages asynchronously over time; Notification Service sends simulated email and SMS receipts.

  • 4-Stage State Machine (PLACED → DELIVERED)
  • Audit trail in `order_events` table
  • Simulated customer alerts & logs
